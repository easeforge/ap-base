## 1. 製作方式總覽

### 1.1 架構

```
操作手冊 = UI 截圖 + 情境引導文字 + Emoji 視覺標記
```

| 組成 | 工具 | 說明 |
|------|------|------|
| UI 截圖 | Playwright (headless Chromium) | 自動化登入 + 逐頁截圖 |
| 文件格式 | Markdown (.md) | 圖片以相對路徑引用 |
| 圖片存放 | `系統設計/image/Base_AP_操作手冊/` | PNG 格式，語意命名 |

### 1.2 前置條件

| 項目 | 需求 |
|------|------|
| 前端服務 | `http://localhost:10180` 運行中 |
| 後端服務 | `http://localhost:10181` 運行中 |
| Redis | 運行中（CAPTCHA 驗證需要） |
| Node.js | 已安裝（用於執行 Playwright） |
| 管理員帳號 | `admin` / 需知道密碼 |

### 1.3 工作流程

```
1. 安裝 Playwright + Chromium
2. 執行截圖腳本（自動登入 → 逐頁導航 → 截圖）
3. 檢查截圖品質
4. 將截圖嵌入操作手冊 Markdown
5. 撰寫情境引導與 Emoji 標記
6. 清理臨時檔案
```

## 2. 截圖自動化流程

### 2.1 自動登入機制

Base AP 的登入需要 CAPTCHA 驗證碼，自動化腳本透過以下方式繞過：

```
1. 呼叫 API 取得 CAPTCHA
   GET http://localhost:10181/api/auth/captcha
   → 回傳 { captcha_key, captcha_svg }

2. 從 SVG 解析驗證碼文字
   SVG 中的 <text> 標籤包含各字元
   用正規表達式提取: /<text[^>]*>([^<])<\/text>/g

3. 呼叫登入 API
   POST http://localhost:10181/api/auth/login
   Body: { account, password, captcha_key, captcha_code }
   → 回傳 { access_token, txn_token, session_id }

4. 將 token 寫入 localStorage
   localStorage.setItem('access_token', ...)
   localStorage.setItem('txn_token', ...)
   localStorage.setItem('session_id', ...)

5. 導航至首頁，系統自動辨識已登入狀態
```

**重要**：API 呼叫必須使用後端完整 URL（`http://localhost:10181`），不能用相對路徑 `/api/...`，因為前端 dev server 不做 API proxy。

### 2.2 頁面導航方式

前端路由規則為 `/{func_code}`，直接用 URL 導航最可靠：

```javascript
// 側邊欄選單的文字選擇器在收合狀態下無法使用
// 因此改用直接 URL 導航
await page.goto('http://localhost:10180/sys_profile');
await page.goto('http://localhost:10180/system_functions');
await page.goto('http://localhost:10180/user_logs');
// ...
```

對應的 `func_code` 清單：

| 頁面 | URL 路徑 |
|------|---------|
| 系統設定資料 | `/sys_profile` |
| 系統功能管理 | `/system_functions` |
| 系統代碼管理 | `/system_codes` |
| 使用者角色設定 | `/user_roles` |
| 角色權限設定 | `/role_rights` |
| 組織設定 | `/organizations` |
| 使用者設定 | `/users` |
| 系統通知管理 | `/system_notifications` |
| 使用者日誌 | `/user_logs` |
| 組織資料維護 | `/tenant_profile` |
| 組織使用者管理 | `/tenant_users` |
| 個人資料 | `/my_profile` |
| 密碼變更 | `/change_password` |

### 2.3 特殊截圖處理

| 情境 | 處理方式 |
|------|---------|
| 系統設定需多張截圖 | 透過 `window.scrollTo()` 捲動頁面，分段截圖 |
| Modal 彈出視窗 | 點擊「新增」按鈕開啟，截圖後用 `Escape` 或 `page.evaluate` 關閉 |
| 側邊欄展開 | 先點擊 toggle 按鈕展開，再點擊各節點 menu-link 展開子選單 |
| 角色權限選取角色 | 透過 `select.selectOption({ index: 1 })` 選取第一個角色 |

### 2.4 Modal 關閉注意事項

Playwright 的 `click()` 在 Modal overlay 存在時會因為 pointer event 被攔截而 timeout。解決方式：

```javascript
// 方式 1: 按 Escape 鍵
await page.keyboard.press('Escape');

// 方式 2: 透過 evaluate 直接操作 DOM（繞過 pointer event 檢查）
await page.evaluate(() => {
  const closeBtn = document.querySelector('.modal-close');
  if (closeBtn) closeBtn.click();
  else {
    const overlay = document.querySelector('.modal-overlay');
    if (overlay) overlay.click();
  }
});
```

## 3. Playwright 截圖腳本

### 3.1 環境安裝

```bash
cd 系統設計/
npm install playwright
npx playwright install chromium
```

### 3.2 完整腳本

以下為經過驗證可正確執行的截圖腳本。使用時存為 `系統設計/screenshot.js`，執行完後刪除。

```javascript
const { chromium } = require('playwright');
const path = require('path');
const fs = require('fs');

const BASE_URL = 'http://localhost:10180';
const API_URL = 'http://localhost:10181';
const OUTPUT_DIR = path.join(__dirname, 'image', 'Base_AP_操作手冊');

if (!fs.existsSync(OUTPUT_DIR)) {
  fs.mkdirSync(OUTPUT_DIR, { recursive: true });
}

async function screenshot(page, name, opts = {}) {
  const filePath = path.join(OUTPUT_DIR, `${name}.png`);
  await page.waitForTimeout(opts.wait || 1200);
  await page.screenshot({ path: filePath, fullPage: opts.fullPage || false });
  console.log(`  ✅ ${name}.png`);
}

async function main() {
  const browser = await chromium.launch({ headless: true });
  const context = await browser.newContext({
    viewport: { width: 1440, height: 900 },
    locale: 'zh-TW'
  });
  const page = await context.newPage();

  console.log('🚀 Starting screenshot capture...\n');

  // ===== Login Page =====
  console.log('📸 Login page');
  await page.goto(BASE_URL);
  await page.waitForTimeout(2000);
  await screenshot(page, 'login_page');

  // ===== Login via API =====
  console.log('\n🔐 Logging in...');

  // Step 1: 取得 CAPTCHA（必須用後端完整 URL）
  const captchaResp = await page.evaluate(async (apiUrl) => {
    const resp = await fetch(`${apiUrl}/api/auth/captcha`);
    return resp.json();
  }, API_URL);

  // Step 2: 從 SVG 解析驗證碼
  const captchaCode = captchaResp.captcha_svg
    .match(/<text[^>]*>([^<])<\/text>/g)
    ?.map(t => t.match(/>([^<])</)?.[1])
    .join('') || '';

  // Step 3: 呼叫登入 API，取得 token 寫入 localStorage
  const loginOk = await page.evaluate(async ({ key, code, apiUrl }) => {
    try {
      const resp = await fetch(`${apiUrl}/api/auth/login`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          account: 'admin', password: 'admin123',  // ← 需換成實際密碼
          captcha_key: key, captcha_code: code
        })
      });
      if (resp.ok) {
        const data = await resp.json();
        if (data.access_token) localStorage.setItem('access_token', data.access_token);
        if (data.txn_token) localStorage.setItem('txn_token', data.txn_token);
        if (data.session_id) localStorage.setItem('session_id', data.session_id);
        return true;
      }
      return false;
    } catch(e) { return false; }
  }, { key: captchaResp.captcha_key, code: captchaCode, apiUrl: API_URL });

  if (!loginOk) {
    console.log('❌ Login failed!');
    await browser.close();
    return;
  }
  console.log('✅ Login successful\n');

  // Step 4: 導航至首頁載入側邊欄
  await page.goto(BASE_URL);
  await page.waitForTimeout(2500);

  // ===== Dashboard =====
  console.log('📸 Dashboard');
  await screenshot(page, 'dashboard');

  // ===== User menu =====
  console.log('📸 User menu');
  const headerRight = await page.$$('.header-right > *, header button, header [role="button"]');
  for (const el of headerRight) {
    const text = await el.textContent();
    if (text && text.includes('管理員')) {
      await el.click();
      await page.waitForTimeout(600);
      await screenshot(page, 'user_menu');
      await page.keyboard.press('Escape');
      break;
    }
  }

  // ===== Sidebar expanded =====
  console.log('📸 Sidebar (expanded)');
  const toggleBtn = await page.$('.sidebar-toggle, .hamburger, [class*="toggle-btn"]');
  if (toggleBtn) {
    await toggleBtn.click();
    await page.waitForTimeout(500);
  }
  const menuLinks = await page.$$('.menu-link');
  for (const link of menuLinks) {
    const text = await link.textContent();
    if (text && (text.includes('系統管理') || text.includes('租戶管理'))) {
      await link.click();
      await page.waitForTimeout(300);
    }
  }
  await screenshot(page, 'sidebar_expanded');

  // ===== 各功能頁面（直接 URL 導航）=====
  const pages = [
    { code: 'sys_profile',          name: 'sys_profile',           section: '5.1 System Profile' },
    { code: 'system_functions',     name: 'system_functions_list', section: '5.2 System Functions' },
    { code: 'system_codes',         name: 'system_codes_list',     section: '5.3 System Codes' },
    { code: 'user_roles',           name: 'user_roles_list',       section: '5.4 User Roles' },
    { code: 'role_rights',          name: 'role_rights',           section: '5.5 Role Rights' },
    { code: 'organizations',        name: 'organizations_list',    section: '5.6 Organizations' },
    { code: 'users',                name: 'users_list',            section: '5.7 Users' },
    { code: 'system_notifications', name: 'system_notifications',  section: '5.8 System Notifications' },
    { code: 'user_logs',            name: 'user_logs_list',        section: '5.9 User Logs' },
    { code: 'tenant_profile',       name: 'tenant_profile',        section: '6.1 Tenant Profile' },
    { code: 'tenant_users',         name: 'tenant_users',          section: '6.2 Tenant Users' },
  ];

  for (const p of pages) {
    console.log(`📸 ${p.section}`);
    await page.goto(`${BASE_URL}/${p.code}`);
    await page.waitForTimeout(2000);
    await screenshot(page, p.name);

    // 系統設定：捲動分段截圖
    if (p.code === 'sys_profile') {
      await page.evaluate(() => window.scrollTo(0, 600));
      await page.waitForTimeout(500);
      await screenshot(page, 'sys_profile_lang');
      await page.evaluate(() => window.scrollTo(0, 1200));
      await page.waitForTimeout(500);
      await screenshot(page, 'sys_profile_theme');
    }

    // 系統功能管理：截取新增 Modal
    if (p.code === 'system_functions') {
      const createBtn = await page.$('button.btn-primary');
      if (createBtn) {
        const btnText = await createBtn.textContent();
        if (btnText && (btnText.includes('新增') || btnText.includes('Create'))) {
          await createBtn.click();
          await page.waitForTimeout(1000);
          await screenshot(page, 'system_functions_modal');
          await page.keyboard.press('Escape');
          await page.waitForTimeout(300);
          // 備用關閉方式
          await page.evaluate(() => {
            const closeBtn = document.querySelector('.modal-close');
            if (closeBtn) closeBtn.click();
            else {
              const overlay = document.querySelector('.modal-overlay');
              if (overlay) overlay.click();
            }
          });
          await page.waitForTimeout(500);
        }
      }
    }

    // 角色權限設定：選取角色
    if (p.code === 'role_rights') {
      const select = await page.$('select');
      if (select) {
        const options = await select.$$('option');
        if (options.length > 1) {
          await select.selectOption({ index: 1 });
          await page.waitForTimeout(1500);
          await screenshot(page, 'role_rights_selected');
        }
      }
    }
  }

  // ===== 隱藏功能頁面 =====
  console.log('📸 Personal: My Profile');
  await page.goto(`${BASE_URL}/my_profile`);
  await page.waitForTimeout(2000);
  await screenshot(page, 'my_profile');

  console.log('📸 Personal: Change Password');
  await page.goto(`${BASE_URL}/change_password`);
  await page.waitForTimeout(2000);
  await screenshot(page, 'change_password');

  // ===== 語系切換器 =====
  console.log('📸 Language switcher');
  await page.goto(BASE_URL);
  await page.waitForTimeout(1500);
  await screenshot(page, 'language_switcher');

  console.log('\n🎉 Screenshot capture complete!');

  const files = fs.readdirSync(OUTPUT_DIR).filter(f => f.endsWith('.png'));
  console.log(`\nGenerated ${files.length} screenshots:`);
  files.sort().forEach(f => console.log(`  - ${f}`));

  await browser.close();
}

main().catch(err => {
  console.error('Error:', err);
  process.exit(1);
});
```

### 5.3 情境引導寫法

每個章節開頭的 💡 **情境**段落應：

- 用第二人稱（「您」）
- 描述具體的使用場景而非功能描述
- 讓讀者能投射自己的實際需求

**好的範例：**

```
> 💡 **情境**：某筆資料被意外修改了，需要查出是誰在什麼時候改的，改了什麼內容。
```

```
> 💡 **情境**：新客戶要使用系統，需要先建立他們的組織資料。
```

**不好的範例（功能描述式，缺乏代入感）：**

```
> 此功能用於管理系統中的組織資料。
```

## 6. 更新維護流程

### 6.1 何時需要重新截圖

| 情況 | 需要重截 |
|------|---------|
| UI 樣式調整（CSS 變更） | ✅ 全部重截 |
| 新增功能頁面 | ✅ 新增對應截圖 |
| 欄位增減 | ✅ 相關頁面重截 |
| 配色主題變更 | ✅ 全部重截 |
| 後端邏輯變更（UI 不變） | ❌ 不需要 |
| 翻譯文字修改 | ⚡ 視影響範圍 |

### 6.2 重新截圖步驟

```bash
# 1. 確認前後端服務運行中
curl -s -o /dev/null -w "%{http_code}" http://localhost:10180
curl -s -o /dev/null -w "%{http_code}" http://localhost:10181/docs
```

### 6.3 新增功能頁面時

1. 在腳本的 `pages` 陣列中新增項目：


### 6.4 Playwright 版本管理

截圖腳本不進版控，僅在需要時從本文件複製。原因：

- 避免 `node_modules/` 和 Playwright 瀏覽器佔用版控空間
- 腳本包含登入密碼，不應進版控
- 執行頻率低（僅 UI 變更時需要），不值得維護為持續整合

### 6.5 已知限制

| 限制 | 說明 | 解法 |
|------|------|------|
| CAPTCHA 解析 | 依賴 SVG `<text>` 標籤解析，若 CAPTCHA 改為圖片則失效 | 改用 Redis 直接讀取驗證碼 |
| 語系可能切換 | 某些頁面操作（如 select）可能觸發語系切換 | 在腳本中加入語系固定邏輯 |
| 動態資料 | 截圖內容取決於資料庫當前資料 | 在乾淨的初始資料環境下執行 |
| 通知彈窗 | 如有啟用中的通知，登入後會彈出遮擋畫面 | 先停用所有通知再截圖 |
| headless 字型 | 無頭模式的字型渲染可能與實際瀏覽器略有差異 | 可改為 `headless: false` 驗證 |
