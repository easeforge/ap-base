# TWN_Area 台灣行政區域設計規格

## 1. 概述

台灣行政區域代碼（TWN_Area）採用內政部行政區域代碼標準，以兩層架構存放於 system_codes 資料表中。第一層為 22 個縣市，第二層為 368 個鄉鎮市區，透過 `note1` 欄位建立上下層關聯。

### 1.1 資料來源

- 標準依據：內政部戶政司 行政區域代碼
- code_etype：`TWN_Area`
- code_ctype：`台灣行政區域`

### 1.2 資料統計

| 層級 | 筆數 | code 格式 | note1 |
|------|------|----------|-------|
| 縣市 | 22 | 3 碼（如 `630`） | 空字串 |
| 鄉鎮市區 | 368 | 6 碼（如 `630001`） | 上層縣市代碼 |
| **合計** | **390** | | |

## 2. 欄位定義

### 2.1 縣市層（第一層）

| 欄位 | 內容 | 範例 |
|------|------|------|
| code_etype | `TWN_Area` | TWN_Area |
| code_ctype | `台灣行政區域` | 台灣行政區域 |
| code | 內政部縣市代碼（3碼） | `630` |
| code_cname | 縣市中文名稱 | 臺北市 |
| code_ename | 縣市英文名稱 | Taipei City |
| order | 顯示次序（北到南） | 1 |
| note1 | **空字串**（表示最上層） | |
| note2 | **空字串** | |

### 2.2 鄉鎮市區層（第二層）

| 欄位 | 內容 | 範例 |
|------|------|------|
| code_etype | `TWN_Area` | TWN_Area |
| code_ctype | `台灣行政區域` | 台灣行政區域 |
| code | 內政部行政區碼（6碼） | `650010` |
| code_cname | 鄉鎮市區中文名稱 | 淡水區 |
| code_ename | 鄉鎮市區英文名稱 | Tamsui Dist. |
| order | 顯示次序（區碼後3碼） | 10 |
| note1 | **所屬縣市代碼** | `650` |
| note2 | **郵遞區號** | `251` |

### 3.2 行政區碼結構

```
代碼結構: CCCNNN
  CCC = 縣市代碼 (3碼)
  NNN = 鄉鎮市區序號 (3碼，001起)

範例:
  650     = 新北市
  650001  = 新北市 板橋區
  650010  = 新北市 淡水區
  630     = 臺北市
  630005  = 臺北市 中正區
```

## 4. 前端聯動設計

### 4.1 兩層聯動流程

```
使用者操作流程：

1. [縣市下拉] 載入 TWN_Area 中 note1 為空的資料 → 顯示 22 縣市
        ↓ 選擇「新北市 (650)」
2. [鄉鎮市區下拉] 載入 TWN_Area 中 note1 = '650' 的資料 → 顯示 29 區
        ↓ 選擇「淡水區 (650010)」
3. [郵遞區號] 自動帶入 note2 值 → 251
```

### 4.2 API 呼叫方式

```typescript
import { getSystemCodesByType } from '../services/systemCodeService';

// 方式一：一次取回全部，前端篩選
const allAreas = await getSystemCodesByType('TWN_Area');
const cities = allAreas.filter(a => !a.note1);         // 縣市
const districts = allAreas.filter(a => a.note1 === '650'); // 某縣市的區

// 方式二：用 search API 搜尋
const result = await getSystemCodes({ search: '淡水' }); // 關鍵字搜尋
```

### 4.3 元件設計建議

```
┌─────────────────────────────────────────────┐
│  縣市    [新北市              ▾]             │
│  鄉鎮市區 [淡水區              ▾]             │
│  郵遞區號 [251] (自動帶入，唯讀)              │
└─────────────────────────────────────────────┘
```

- 初始狀態：縣市下拉載入 22 筆，鄉鎮市區下拉為空（disabled）
- 選擇縣市後：鄉鎮市區下拉啟用，載入對應區域
- 選擇鄉鎮市區後：自動帶入 note2（郵遞區號）
- 清除縣市時：同步清除鄉鎮市區和郵遞區號

## 5. 資料維護

### 5.1 資料更新時機

- 內政部公告行政區域調整時（合併、改制、更名）
- 可透過系統代碼管理頁面手動維護
- 或透過 SQL 批次更新

### 5.2 注意事項

- 行政區碼變更時，需同步更新引用該代碼的業務資料
- 停用的行政區建議設 `is_active = FALSE`，不建議直接刪除
- 郵遞區號（note2）由中華郵政管理，與行政區碼無直接對應關係，需分別維護
