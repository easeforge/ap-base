## Phase 9：前端語系機制改造

**Commit**: `6c2b061` feat: 前端語系機制改造 - 動態載入 + 語系切換器 (Phase 9)

### 改動範圍（6 files）

#### 新增依賴
- `i18next-http-backend` — npm install

#### i18n.ts
- 加入 `i18next-http-backend`，從 `GET /api/sys_languages/{lang_code}` 動態載入翻譯
- 自訂 `parse` 函式解析 API 回傳的 `lang_data` 欄位
- 自訂 `customHeaders` 帶入 auth token
- 保留靜態 zh-TW/en 翻譯檔作為 `partialBundledLanguages` fallback

#### SystemContext.tsx
- 新增 `LanguageOption` interface（code, cname, ename, short_name）
- 新增 `availableLanguages`、`defaultLanguage` state
- 新增 `loadActiveLanguages()` — 從 `GET /api/system/languages`（公開端點）載入

#### LanguageSwitcher.tsx
- 從 `useSystem()` 取得 `availableLanguages`
- 1 個語系 → 不顯示
- 2 個語系 → 按鈕切換（原有 UI）
- 3+ 個語系 → 下拉選單
- 顯示文字使用 `short_name`

#### LanguageSwitcher.css
- 新增 `.lang-select` 下拉選單樣式
