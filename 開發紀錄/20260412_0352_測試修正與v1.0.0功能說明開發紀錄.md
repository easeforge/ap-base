## 修正項目

### 1. Dashboard 登入後 console 錯誤

**Commit**: `c34979e`

**問題**:
- MUI Menu 不接受 React.Fragment 作為子元素（37 個警告）
- `Function code not found: dashboard`（dashboard 不在 system_functions 中）

**修正**:
- MainLayout: Menu 子元素從 `React.Fragment` 改為 `flatMap` 回傳陣列
- DashboardPage/HomePage: 移除不存在的 `dashboard` func_code 日誌記錄（首頁不是功能頁面，不需要記日誌）
- 清除 DashboardPage 多餘的 debug console.log

### 2. console.log/warn 噪音清除

**Commit**: `e886e9f`

- `userLogHelper.ts`: 移除所有 debug console.log，功能代碼不存在時靜默跳過（不再顯示 warn）
- `Sidebar.tsx`: 移除選單載入 console.log

### 3. CORS 設定 + userLog module_item 錯誤

**Commit**: `771e3c5`

**問題 1 — CORS**:
- `allow_origins=["*"]` 搭配 `allow_credentials=True` 違反 CORS 規範
- 瀏覽器每次進入頁面都會報 CORS 紅色錯誤

**修正**: CORS allow_origins 從 `["*"]` 改為明確列出 `["http://localhost:10180", "http://127.0.0.1:10180"]`

**問題 2 — userLog**:
- `logView()` 使用 `'View'` 作為 module_item
- 資料庫 CHECK constraint 只允許 `Create/Read/Update/Delete/Print/File/Login`
- 每次進入任何頁面都會觸發 500 Internal Server Error

**修正**: `logView` 的 module_item 從 `'View'` 改為 `'Read'`

### 4. Windows 環境時區驗證失敗

**Commit**: `f8130af`

**問題**: 系統設定儲存時報「無效的時區設定: Asia/Taipei」

**原因**: Windows Python 的 `ZoneInfo` 需要 `tzdata` 套件才能辨識時區名稱，缺少時所有時區驗證都會失敗

**修正**: 安裝 `tzdata` 並加入 `requirements.txt`

### 5. 使用者下拉選單動態化

**Commit**: `e431a34`（前一批次已記錄，此處補充）

- MainLayout 不再寫死 my_profile/change_password/logout
- 改為從 `personal_function` 節點動態載入子功能
- 可在系統功能管理中自由新增/調整個人化功能項目
